# Paper sports agent (PAPER MONEY ONLY)
`agent.py` studies upcoming games before tip-off with a 16-point checklist and places a fake $2 bet only when
80%+ of applicable checks pass and the mandatory gates (edge, volume, price range, regular season) pass.
Results and reasoning are committed to `state/` after every run (`state/latest_report.md`).
No real money, no accounts, no keys. Local mock site: `python3 server.py`.
